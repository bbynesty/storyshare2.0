# StoryShare

StoryShare - это веб-приложение для обмена историями, где пользователи могут создавать, читать и делиться своими историями.

## Особенности

- Создание и публикация историй
- Поиск историй
- Случайные цитаты из историй
- Аутентификация пользователей
- Современный дизайн с пастельной цветовой схемой

## Технологии

- Frontend: React, Material-UI
- Backend: C++, Crow Framework
- База данных: In-memory (в будущем планируется переход на SQLite)

## Установка и запуск

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
mkdir build
cd build
cmake ..
cmake --build .
./server
```

## Разработка

1. Клонируйте репозиторий
2. Установите зависимости
3. Запустите frontend и backend
4. Внесите изменения
5. Создайте pull request
