# Инструкция по деплою на Render

## Подготовка

1. Убедитесь, что ваш репозиторий на GitHub содержит все необходимые файлы:
   - `Dockerfile` (для бэкенда)
   - `render.yaml` (для автоматической настройки)
   - `.dockerignore`

## Вариант 1: Автоматический деплой через render.yaml (Рекомендуется)

1. **Войдите в Render**:
   - Перейдите на [render.com](https://render.com)
   - Войдите через GitHub

2. **Создайте новый Blueprint**:
   - Нажмите "New" → "Blueprint"
   - Выберите репозиторий `bbynesty/storyshare2.0`
   - Render автоматически обнаружит `render.yaml` и настроит оба сервиса

3. **Дождитесь деплоя бэкенда**:
   - Бэкенд будет деплоиться первым (может занять 5-10 минут)
   - После деплоя скопируйте URL бэкенда (например, `https://storyshare-backend.onrender.com`)

4. **Обновите переменную окружения фронтенда**:
   - В панели Render откройте сервис `storyshare-frontend`
   - Перейдите в "Environment"
   - Обновите `REACT_APP_API_URL` на URL вашего бэкенда
   - Нажмите "Save Changes" → "Manual Deploy" → "Deploy latest commit"

## Вариант 2: Ручной деплой

### Деплой бэкенда:

1. **Создайте Web Service**:
   - Нажмите "New" → "Web Service"
   - Подключите репозиторий `bbynesty/storyshare2.0`

2. **Настройки**:
   - **Name**: `storyshare-backend`
   - **Environment**: `Docker`
   - **Dockerfile Path**: `./Dockerfile`
   - **Docker Context**: `.` (точка)
   - **Plan**: Free

3. **Переменные окружения**:
   - `PORT`: `8080` (Render автоматически установит, но можно указать явно)

4. **Нажмите "Create Web Service"**

### Деплой фронтенда:

1. **Создайте Static Site**:
   - Нажмите "New" → "Static Site"
   - Подключите репозиторий `bbynesty/storyshare2.0`

2. **Настройки**:
   - **Name**: `storyshare-frontend`
   - **Root Directory**: `frontend`
   - **Build Command**: `npm install && npm run build`
   - **Publish Directory**: `build`

3. **Переменные окружения**:
   - `REACT_APP_API_URL`: URL вашего бэкенда (например, `https://storyshare-backend.onrender.com`)

4. **Нажмите "Create Static Site"**

## Важные замечания

⚠️ **Бесплатный план Render**:
- Сервисы "засыпают" после 15 минут бездействия
- Первый запрос после "сна" может занять 30-50 секунд (cold start)
- Для продакшена рекомендуется платный план

⚠️ **CORS настройки**:
- Убедитесь, что в `backend/src/main.cpp` настроен CORS для вашего фронтенда
- Добавьте URL фронтенда в список разрешенных источников

⚠️ **Порт**:
- Render автоматически устанавливает переменную `PORT`
- Убедитесь, что ваш C++ сервер использует эту переменную
- Если нет, нужно будет обновить код бэкенда

## Проверка работы

1. **Проверьте бэкенд**:
   - Откройте `https://your-backend.onrender.com/health` (если есть health check)
   - Или попробуйте любой API endpoint

2. **Проверьте фронтенд**:
   - Откройте URL фронтенда
   - Проверьте, что запросы к API работают

## Обновление кода

После каждого push в GitHub, Render автоматически передеплоит сервисы. Если нужно передеплоить вручную:
- Откройте сервис в панели Render
- Нажмите "Manual Deploy" → "Deploy latest commit"

## Решение проблем

### Бэкенд не запускается:
- Проверьте логи в панели Render
- Убедитесь, что Dockerfile корректен
- Проверьте, что все зависимости установлены

### Фронтенд не подключается к бэкенду:
- Проверьте переменную `REACT_APP_API_URL`
- Убедитесь, что CORS настроен правильно
- Проверьте, что бэкенд запущен и доступен

### Ошибки сборки:
- Проверьте логи сборки в Render
- Убедитесь, что все зависимости указаны в `package.json` (фронтенд) и `CMakeLists.txt` (бэкенд)
